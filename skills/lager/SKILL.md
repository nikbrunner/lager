---
name: lager
description: Use lager to work with declared local Git repositories. It lists the inventory of checkouts and their state, registers, clones and removes repositories, creates and removes worktrees, and opens terminal sessions for checkouts. Use it when a task names lager, repositories under a shared root, or a worktree or session for a repository.
---

Run `lager skill` and follow the guide it prints. The guide comes from the installed lager, so it describes the commands of that version.

If `lager` is not installed or `lager skill` fails, follow `references/setup.md`.
